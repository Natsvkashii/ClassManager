1. VERSIONE PORTABLE (NESSUNA INSTALLAZIONE RICHIESTA):
   - Fai doppio clic su "Gestione-Corsi-2.1.0-Portable.exe"
   - È un eseguibile singolo autonomo (single-file .exe) che si avvia direttamente
     senza installazione, senza creare collegamenti e senza modificare il registro.

2. INSTALLER & UPGRADER NATIVO WINDOWS 11 (.EXE):
   - Fai doppio clic su "Gestione-Corsi-2.1.0-Setup.exe"
   - Installa o aggiorna automaticamente l'applicazione in:
     %LOCALAPPDATA%\Programs\GestioneCorsi\GestioneCorsi.exe
   - Crea i collegamenti "Gestione Corsi" sul Desktop e nel Menu Start di Windows 11.
   - Registra il programma nelle App Installate di Windows 11 (Impostazioni -> App).
   - Configura la sincronizzazione automatica con Microsoft OneDrive (%OneDrive%\GestioneCorsi).
